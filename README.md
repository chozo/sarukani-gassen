# さるかに合戦 やられる前にヤレ

昔話「猿蟹合戦」が題材のミニWebゲーム。木の上の猿が投げてくる青柿をカニでかわしながら、仲間（蜂・栗・針・臼）の力で猿をこらしめる。
**蜂と栗で猿を追い立て、臼の落下ラインに追い込んで仕留める**のが勝ち筋。
猿を倒すと、もっと強い猿が次々に出てくる勝ち抜き式。**何匹こらしめられるか**で称号が決まる。

- 公開先：https://game.chozo.net/sarukani-gassen/
- リポジトリ：https://github.com/chozo/sarukani-gassen
- 遊び方：`index.html` をブラウザで開くだけ（単一ファイル・外部アセットなし・音は Web Audio で合成）
- 画面：縦 9:16（スマホ向け、PC でも可）

## 画面

- タイトル：ロゴ、ひとこと（「強くなる猿を何匹こらしめられる？」）、仲間のアイコン、最高記録、「はじめる」「あそびかた」だけを置く。背景では猿が蜂に追われ、カニが仲間と歩く。
- あそびかた：タイトルの「あそびかた」から開く（Esc で戻る）。操作、仲間5種の説明、コツ（追い込みと臼ゾーン）、勝ち抜きと称号の一覧をまとめている。ここからも始められる。

## ルール

- カニの体力（ハート）は 3 から始まる。青柿に当たると 1 減る。**カニの体力が 0 になるとゲーム終了**。
- 猿の「懲らしめゲージ」を 0 にすると、猿が降りてきて謝り、とぼとぼ退場する。**ハートの最大数が 1 増え（最大 7 個まで。7 個になったらそれ以上は増えない）**、体力も 1 回復する。すぐに**次の猿が上から降ってくる**。
- 持てる仲間は 1 つまで。仲間は地面にランダムで出て、約 7.5 秒で消える。出る場所はカニから離れていて、半分以上は猿の真下付近（＝柿が降ってくる所）。
- **ゲージの最後の 20%（「臼」ゾーン）は臼でしか削れない。** とどめは必ず臼（どの猿でも同じ）。

### 勝ち抜きと猿の強さ

n 匹目の猿ほど強い。HUD の中央に「n匹目」、ゲージの左に猿の名前が出る。登場時に体力と投げる速さの上がり幅を表示する。

| | 1匹目 | 2匹目 | 3匹目 | 5匹目 | 8匹目 | 11匹目〜 |
|---|---|---|---|---|---|---|
| 名前 | 子猿 | いたずら猿 | 暴れ猿 | ボス猿 | 猿王 | 猿王 その4 … |
| 体力（ゲージ） | 100 | 130 | 160 | 220 | 310 | 400（上限） |
| 投げる間隔 | 基準 | ×0.9 | ×0.81 | ×0.66 | ×0.48 | 下限 0.42 秒 |

- 難しさの時間（2連投・3連投・フェイントが出始める時刻、投擲の速さの上がり方）を、n 匹目ごとに 20 秒ぶん前倒しする。
- 落ち着いているときの歩く速さが 6% ずつ上がる（上限 1.45 倍）。
- 見た目：2匹目からはちまきを巻き、色が変わる（白→青→緑→赤→紫→黒→金）。少しずつ大きくなる。8匹目からは額に星。
- 体力 250 以上（6匹目〜）は臼を 2 回当てないと倒せない。

### 称号（倒した数）

| 倒した数 | 0 | 1 | 2 | 3 | 5 | 7 | 10 | 15 | 20 |
|---|---|---|---|---|---|---|---|---|---|
| 称号 | まだまだ子ガニ | 一人前のカニ | 猿こらしめ係 | 柿の木の番人 | カニ名人 | さるかに合戦の勇者 | カニ大将 | 伝説の大ガニ | カニ神さま |

新しい称号を得るとその場で「称号ゲット！」と表示する。結果画面には称号と「あと ◯匹で『…』」を出す。

### 仲間

| 仲間 | 使い方 | 役割 | ダメージ |
|---|---|---|---|
| 針 | 拾うと即発動（手持ちは埋まらない） | 2.6 秒間、カニの真上へ連射 | 2 / 発 |
| 蜂 | アクションで放つ | 猿を追い回す。いる間（6.5 秒）猿は投げずに逃げ回る。刺すと 17.5%、追われている間は 2.4 秒ごとに 15% で熟柿を落とす | 1 / 0.6 秒 |
| 栗 | アクションで地面に置く | 2.4 秒で地面から**猿めがけて打ち上がり**（横へは 80px まで曲がれる）、猿の高さで破裂する。破裂の半径 56px に猿が入っていれば当たる。猿は驚いて固まったあと、**栗を置いた位置の反対側の枝の端**へ逃げる。当たると 30% で熟柿を落とす | 18 |
| 臼 | アクションで仕掛ける（持っている間はカニが半分の速さ） | 自分で幹まで転がり、登り、仕掛けた位置の真上の「待機枝」で待つ。猿が真下に来ると自動で落ちる。外れたら地面に残るので拾って仕掛け直せる | 45 |

### 猿の動き

- 枝の上を移りながら、カニを狙って青柿を投げる。投げる前に振りかぶり、地面に着弾予告（×印）が出る。カニの移動方向を少し先読みする。
- 時間とともに投擲間隔が短くなり（1.8 秒 → 0.8 秒）、30 秒以降は 2 連投、65 秒以降は 3 連投、45 秒以降はフェイントも混ざる。ゲージが半分を切ると怒って更に速くなる。
- **落ち着いている猿は臼の下を避ける**（臼の列の手前で「!? 臼だ」と止まり、真上に来られたら横へよける）。蜂に追われているとき・栗に驚いて逃げているときは臼に気づかない。→ 追い込みが必要。

### 臼の落下判定（画面での見え方）

- 臼が待機すると、真下に**命中幅（±26px）の帯**が出る。猿が帯に入ると帯が赤くなる。
- 臼は「いま落ちたら、着いた瞬間に猿がどこにいるか」を猿の**いまの動き**（走る速さ・ジャンプの着地点）から読んで落ちる。走ってくる猿には手前で落ちる。猿が急に止まる・段を跳ぶと外れる。
- 臼が猿の高さを通った瞬間の位置関係を、点線の判定枠・猿の中心点・ずれの線で約 1.5 秒残す（「命中！」または「判定の外」と「すり抜けた！ずれ ◯px」）。
- 臼を持っている間は、仕掛け先（待機位置と命中幅）を予告表示する。栗・蜂を持っている間は、猿の横に「逃げる向き」の矢印が出る。

### 栗の破裂（画面での見え方）

- 栗を持っている間と、置いて破裂を待つ間は、「いま破裂したら飛ぶ先」への点線と破裂の円を出す。猿が円に入っていればオレンジ、入っていなければ白で「とどかない」と表示する。
- 破裂した瞬間の円と猿の中心を約 1 秒残す（当たりは赤、外れは白い線で距離を結び、「とどかず あと ◯px」と出す）。

### 熟柿キャッチ

- 熟柿はゆっくり落ちる。地面に影が出て、近づくとカニのキャッチ範囲（点線の枠）が光る。
- 取ると +100 点、体力が減っていれば 1 回復（そのときのハートの最大数まで）。取り逃すと「おしい！あと ◯px」とカニの判定の端からの距離を表示する。

### スコア

与えたダメージ ×10 ＋ 熟柿 ×100 ＋ 臼の命中 ×300 ＋ 猿を倒したボーナス。
倒したボーナスは 1 匹ごとに「n 匹目 × 500 ＋ 速さ（(60 − その猿にかかった秒) × 20、0 未満は 0）」。
ベストスコアと最多こらしめ数は端末に保存し、タイトル画面に表示する（保存できない環境でも遊べる）。

## ファイル構成

```text
app/
├── index.html            # ゲーム本体（これだけで動く）
│     <script id="logic">  純ロジック：調整値 CFG、出現抽選、臼の落下判定、ダメージ計算、猿の AI、
│                          ワールドのシミュレーション（DOM・描画・音に依存しない）
│     <script id="game">   描画（Canvas 2D）、入力、効果音・BGM（Web Audio）、HUD、確認用の入口 window.__game
├── tests/
│   ├── load-logic.mjs     # index.html から logic ブロックだけ取り出して Node で評価
│   ├── logic.test.mjs     # 単体テスト（判定の境界値、臼の落下タイミング、栗で逃げる方向、蜂の妨害、出現抽選、スコア、勝ち抜き・称号）
│   └── balance.test.mjs   # ボットによるバランス確認（臼なしでは勝てない／臼だけでは当たらない／追い込めば勝てる／勝ち抜き）
├── public/
│   ├── favicon.svg        # ファビコン（カニ）。index.html から ./favicon.svg で参照
│   └── ogp.png            # SNS 共有用の OGP 画像（1200×630、npm run ogp で作る）
├── tools/build-dist.mjs   # 公開用ファイルを dist/sarukani-gassen/ に書き出す（index.html と public/ の中身）
├── tools/e2e.mjs          # ブラウザ確認（playwright-core + インストール済み Chrome）
├── tools/promo/           # 告知動画の撮影と台本（scenario.js・promo.css・make-bgm.mjs・record.mjs・stage.js）
├── tools/ogp/make-ogp.mjs # OGP 画像の生成（ゲーム画面を撮ってロゴ・カニと並べる）
├── wrangler.jsonc         # Cloudflare Workers（静的アセット）の設定
├── package.json
├── LICENSE
└── README.md
```

調整値はすべて `index.html` の `CFG`（logic ブロック冒頭）にまとめている。

## テストと確認

```bash
npm install          # playwright-core（ブラウザ確認用。ゲーム本体は依存なし）
npm test             # 単体テスト + バランス確認（Node 18 以上）
npm run e2e          # ブラウザ確認（Chrome が必要。CHROME_PATH で場所を指定可）
npm run shots        # 上に加えて shots/ に場面ごとのスクリーンショットを保存
E2E_URL=https://game.chozo.net/sarukani-gassen/ npm run e2e   # 公開先で確認
npm run ogp          # public/ogp.png を作り直す（乱数の種とコマ数を固定しているので毎回同じ絵）
```

### ファビコンと OGP 画像

- `public/` に置き、公開時は `public/` の中身を公開ルート（`index.html` と同じ階層）に置く想定。`index.html` は `./favicon.svg` を参照し、OGP のメタタグは `https://game.chozo.net/sarukani-gassen/` を前提にした絶対 URL（公開名 `sarukani-gassen`）。
- `index.html` を直接開いたときは `public/` を参照しないので、ファビコンは出ない。`npm run e2e` は公開時と同じ並びで配る小さなサーバーを立てて確認する（ファビコン・OGP 画像の取得も確認）。
- OGP 画像は、確認用の入口 `window.__game` で「臼を仕掛けて蜂で猿を追い立てる」場面まで進めて撮ったゲーム画面に、ロゴ・ひとこと・公開 URL・カニのイラスト（`favicon.svg`）を重ねている。

バランス確認の結果（特に書かないものはカニを無敵にしたボット、2026-11-15 時点）：

- 1匹目を臼を使わずに攻める：4 分かけても「臼」ゾーンで止まり、倒せない（8/8）
- 1匹目に、蜂・栗を使わず臼を猿の真下に置くだけ：90 秒で臼の命中 0 回
- 1匹目に、臼を仕掛けて蜂・栗で追い込む：12/12 で倒せる、平均約 35 秒
- 勝ち抜き（追い込みボット・8 分）：7 匹倒せる。1匹目は平均 34 秒、5匹目は平均 61 秒
- 何もしないカニは 90 秒以内に倒れる
- 栗の命中率（20 試合）：猿の近くに置くボットで 89%、でたらめな位置に置いても 65%
- 青柿を完璧によけるボット（被弾あり、ハートが増える）：8 試合で 1〜12 匹倒し、すべていずれ倒れた（25 分以内）。ハートの上限を 3 のままにすると 2〜4 匹
- ブラウザの通しプレイ（同じボット）：6 匹倒し、7匹目で 428 秒目に倒れた

ヘッドレスでは音と実機の描画速度は確認できない。スマホ実機での確認は未実施。

### 確認用の入口 `window.__game`

`start(seed)`、`manual(true)` + `step(n, input)`（1/60 秒単位で進める）、`setSpeed(s)`、`give(kind)`、`spawnItem(kind, x)`、`world`（状態）、`drainEvents()`、`render()`、`audio`。

## 告知動画

```bash
npm run promo                         # build → BGM 合成 → 全コマ撮影 → MP4 書き出し
PROMO_EVERY=15 npm run promo          # 確認用：15コマおきの一覧画像だけ作る
PROMO_ENCODE_ONLY=1 npm run promo     # 撮り直さずに音だけ書き出し直す（BGM の音量を変えたときなど）
```

- 出力はアプリの隣の `../video/`：`sarukani-gassen-promo.mp4`（縦 1080×1920・30fps・約 28 秒）、`-cover.jpg`（表紙）、`-sheet.jpg`（2秒おきの一覧）。動画はリポジトリに含めない。
- 台本は `tools/promo/scenario.js`。乱数の種 27 で、tests の追い込みボットと同じ動きを `window.__promoBot` として置いて撮る。構成は「臼が猿に落ちる瞬間（スロー）→ タイトル → 柿をよけて仲間を拾う → 蜂・栗で追い込む（×3）→ 臼でこらしめる → 次の猿 → 何匹こらしめられる？ → エンドカード」。称号は動画に出さない（「称号ゲット！」の帯は隠す）。
- BGM は `make-bgm.mjs` で一から合成したポップな曲（外部音源なし）。効果音より約 12 dB 小さくし、全体を -14 LUFS にそろえる。
- 撮影用にゲームへ足した入口：`step(dt)`（dt 秒進めて描画）、`state()`、`input()`、`audio.capture / drain / render`。帯・ボタンの押し込み・結果画面の待ちなどのタイマーはゲーム内の時間で数える（手動進行中は実時間では進まない）。

## 公開（Cloudflare Workers + Static Assets）

```bash
npm run build        # dist/ を空にしてから dist/sarukani-gassen/ に index.html・favicon.svg・ogp.png を書き出す
npx wrangler deploy --dry-run
npm run deploy       # build + wrangler deploy
```

- Worker 名 `sarukani-gassen`。ルートは `game.chozo.net/sarukani-gassen` と `game.chozo.net/sarukani-gassen/*`（ゾーン `chozo.net`）だけで、workers.dev は使わない。
- 2026-11-15 に初回公開。公開 URL・`favicon.svg`・`ogp.png` が 200 を返し、末尾スラッシュなしは `/sarukani-gassen/` へ移動すること、同じドメインのトップと他のゲームが表示されること、公開先に対する `npm run e2e` がすべて通ることを確認した。
